# EasyBizzy Solo Scrum Working Agreement

Sprint length: 7 days
Sprint review + planning: Sunday evening

Rules:
- One sprint goal sentence only.
- Maximum 2 vertical slices per sprint.
- Scope is frozen once sprint starts.
- New ideas go to backlog.
- Every feature must be built as a vertical slice:
  1. Minimal data model
  2. Backend queries + mutations
  3. Guards (tenant + role + subscription)
  4. Minimal mobile-first UI
  5. Manual test checklist
  6. Lint + build pass

Definition of Done must be satisfied before marking a task complete.
